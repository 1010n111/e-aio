# e-aio・企业级一体化管理系统

> **通用能力大一统 + 业务逻辑按企业定制**
>
> 的全开源企业级管理系统

`e-aio` 是一套**全开源、自托管（Self-hosted）、模块化单体架构**的企业级一体化管理系统。它将 OA、CRM、库存、财务、人力资源、项目管理、供应链、工作流、审批、权限、审计、报表 BI、AI 等企业通用能力**大一统到一个平台**，同时通过主数据与配置化能力及模块化设计，允许**业务逻辑按每家企业的需求深度定制**。

项目**不采用 SaaS 模式、不收取任何订阅费 / 授权费 / 使用费**，全部代码开源、接受社区 PR，企业拥有数据的完全自主权。

## 🏗 架构

### 模块化单体（Spring Modulith）

本项目**不采用微服务架构**，采用 **Spring Modulith 模块化单体**：

* **基于 RuoYi 蓝本**：以 RuoYi-Vue 前后端分离版（MIT）为代码蓝本，后端用 Spring Boot 4.x + Spring Modulith 2.x 重构为模块化单体，前端基于 RuoYi-Vue3（Vue3 + Vite + Element Plus），叠加母子公司权限 / 双审计 / 主数据 / AI
* **模块边界**：按业务域划分模块（`oa`、`crm`、`inventory`、`finance`、`workflow`、`audit`、`security`、`approval`、`ai`、`hr`、`project`、`scm`、`report`、`portal`、`mdm`、`marketing`、`service`、`fund`、`integration`、`mobile`、`i18n`），模块间通过明确公共 API 交互
* **业务模块调用通用能力**：业务模块（按企业定制）单向调用通用能力（流程 / 权限 / 审计 / 报表 / AI 等），依赖方向为"业务模块 → 通用能力"，禁止反向依赖

* **依赖单向**：依赖方向清晰，禁止循环依赖，ArchUnit 强制校验

* **事件驱动**：模块间通过 Spring 应用事件异步解耦（如 "合同创建"→触发 "应收生成"）

* **独立数据归属**：每个模块拥有独立 Schema / 表空间，跨模块通过应用层接口访问

* **模块独立演进**：可独立打包、独立测试、独立扩展，未来必要时可平滑拆分

### 母子公司多级权限

* 集团 - 子公司无限级组织树

* 子公司数据隔离（数据权限），集团统一管控 / 子公司自治可配

* 角色继承与覆盖、跨公司审批与审计

* 职责分离（SoD）满足内控与审计合规

### 双维度审计

* **系统操作审计**：全操作留痕、日志防篡改、全场景溯源

* **财务专项审计**：凭证 / 对账 / 报表可追溯，合规级审计输出
