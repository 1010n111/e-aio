## 开发队列（HLD 13.2）

P0 工程骨架 + common → P1 平台底座（platform/iam/audit/workflow/approval/mdm/…）→ P2 业务域（oa/crm/inventory/finance/hr/project/scm/…）→ P3 开放定制与 AI 增强。

写代码前先确认目标模块属于哪一批，不跨批次提前实现。常用章节：HLD 2.2 模块边界 / 2.6 API / 5.1 common / 13.2 队列。
